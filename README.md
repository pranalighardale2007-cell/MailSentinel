# 🛡️ AI-Powered Email Threat Detection System

An AI-powered web application that detects potentially malicious, phishing, and suspicious emails. The system analyzes email content and helps users identify possible security threats.

## 📌 Project Overview

Phishing and malicious emails are becoming increasingly common. Attackers often create emails that look genuine and use fake links, suspicious domains, and social engineering techniques to deceive users.

This project provides a simple web-based platform where users can analyze an email and receive a threat assessment.

## 🎯 Objectives

- Detect phishing and suspicious emails.
- Analyze email content and identify potential threats.
- Help users recognize malicious links and suspicious information.
- Reduce the time required for manual email investigation.
- Provide a simple and user-friendly interface.
- Support cybersecurity awareness and email investigation.

## ✨ Features

- 📧 Email threat analysis
- 🤖 AI/ML-based detection
- 🔍 Suspicious content analysis
- 🔗 URL/link analysis
- 🌐 Domain/IP investigation
- ⚠️ Threat classification
- 📊 Easy-to-understand results
- 🖥️ User-friendly Streamlit interface
